طريقة الرفع على Railway
========================

1) ارفع جميع الملفات الموجودة داخل هذا المجلد إلى جذر مستودع GitHub.
   يجب أن يكون package.json و index.js في جذر المستودع، وليس داخل مجلد إضافي.

2) اربط المستودع بخدمة Railway وأضف المتغيرات التالية، كل متغير لوحده:

NODE_ENV=production
PORT=3000
BOT_TOKEN=توكن البوت
ADMIN_ID=آيدي المدير الرقمي
DATABASE_URL=${{Postgres.DATABASE_URL}}
PUBLIC_WEBHOOK_URL=https://${{RAILWAY_PUBLIC_DOMAIN}}

BINANCE_API_KEY=مفتاح Binance API العادي
BINANCE_API_SECRET=المفتاح السري المقابل له
BINANCE_PAY_ID=معرّف Binance Pay ID
BINANCE_API_BASE_URL=https://api.binance.com

3) لا تضع علامات اقتباس حول القيم في Railway.

4) مفتاح Binance المطلوب للتحقق من التحويلات هو مفتاح API عادي للحساب بصلاحية القراءة.
   لا تستخدم Merchant API Key بدلاً منه.

5) إذا كان مفتاح Binance مقيّداً بعناوين IP، يجب السماح بعنوان الخروج الخاص بخدمة Railway،
   أو إزالة تقييد IP عن المفتاح المخصص للقراءة فقط.

6) بعد حفظ المتغيرات نفّذ Redeploy.

ملاحظات الإصلاح
================
- لا يوجد اتصال بوسيط Render داخل binancePay.js.
- التحقق يتصل مباشرة بواجهة Binance الموقعة بنفس منطق البوت الأول.
- تتم معالجة فرق وقت السيرفر تلقائياً.
- توجد عناوين Binance احتياطية عند تعذر الوصول إلى العنوان الأساسي.
- لا يتم تنفيذ سحب أو تداول؛ الاستخدام هنا لقراءة سجل التحويلات والتحقق منها فقط.
- عند فشل Binance سيظهر رمز تشخيص للمساعدة في معرفة السبب الحقيقي.

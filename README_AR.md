# نسخة البوت المطابقة لـ a-store-CD

هذه النسخة تعيد بناء البوت السابق على نفس هيكل وواجهة `a-store-CD-main` المرفق كمرجع، بما في ذلك طريقة المنتجات، المحفظة، الطلبات، الدعم، لوحة الإدارة، والهدايا والإحالات.

## الدفع — مطابق للمرجع

- **Binance ID**: المستخدم يحول إلى Binance ID ثم يرسل `Order ID`، والبوت يتحقق من العملية تلقائياً عبر Binance API ذات صلاحية القراءة.
- **SuperQi**: المستخدم يرسل إيصال التحويل، ويصل إلى الأدمن للموافقة أو الرفض.
- شحن المحفظة يستخدم نفس الطريقتين أيضاً.

## قاعدة البيانات القديمة

لا تحتاج قاعدة جديدة. أول تشغيل يقوم تلقائياً بـ:

- إبقاء المستخدمين والأرصدة والمنتجات والمخزون القديم.
- تحويل نوع المنتج القديم `single` إلى `code`.
- تحويل نوع المنتج القديم `bulk` إلى `private`.
- نقل صور المنتجات القديمة من صيغة الوصف السابقة إن وجدت.
- الحفاظ على الوصف النصي القديم وإظهاره في النظام الجديد.
- محاولة نقل رقم SuperQi وسعر صرف IQD من إعدادات الدفع القديمة إن كانا مضبوطين.
- إنشاء الجداول/الأعمدة الجديدة فقط عند الحاجة، بدون حذف الجداول القديمة.

## متغيرات Railway المطلوبة

استخدم `.env.example` كمرجع. المتغيرات الأساسية:

```env
BOT_TOKEN=...
ADMIN_IDS=...
DATABASE_URL=...
BINANCE_API_KEY=...
BINANCE_API_SECRET=...
BINANCE_PAY_ID=...
SUPERQI_NUMBER=...
IQD_RATE=1500
```

### INVENTORY_ENCRYPTION_KEY

الأفضل إضافته مرة واحدة بقيمة 64 خانة Hex وعدم تغييره بعد ذلك. إذا لم تضفه، النسخة تعمل تلقائياً بمفتاح توافق مشتق من `BOT_TOKEN` حتى لا يتوقف النشر القديم، لكن بعدها يجب عدم تغيير `BOT_TOKEN` قبل تثبيت مفتاح صريح لأن المخزون يُشفّر عند التشغيل.

## التشغيل

```bash
npm install
npm start
```

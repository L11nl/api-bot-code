# v11.6 — ترتيب لوحة الإدارة

هذه النسخة تغيّر واجهة لوحة الإدارة فقط وتبقي منطق المنتجات والدفع والشبكة كما هو في v11.5.

## الاستبدال
استبدل الملف:

`src/bot.js`

ثم اعمل Redeploy.

## ترتيب لوحة الإدارة الجديد
- المنتجات والمخزون
- الطلبات والتسليم
- الدفع والمحفظة
- العملاء والتواصل
- التسويق والإشعارات
- الشبكة والشركاء والحسابات (Master) / الشبكة والحسابات (Client)
- إعدادات المتجر

كل قسم يحتوي أدواته فقط، مع أزرار رجوع واضحة.
